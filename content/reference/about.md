## เว็บไซต์นี้คืออะไร

Databricks SQL Learning Hub คือเวอร์ชันเว็บไซต์ของชุดสื่อการสอน "Databricks SQL สำหรับคนทำงาน: จากศูนย์สู่การใช้งานจริง" ที่ปรับปรุงและเรียบเรียงใหม่ให้เรียนด้วยตนเองได้ ประกอบด้วยบทเรียน 25 บท คลังสูตร SQL 50 สูตร และแบบฝึกหัด 55 ข้อพร้อมเฉลย ทุกตัวอย่างใช้ข้อมูลจำลอง

## แหล่งที่มาของเนื้อหา

เนื้อหาพัฒนาจากชุดเอกสารเดิม ได้แก่

| เอกสาร | นำมาใช้อย่างไร |
|---|---|
| SQL Handbook (12 Module + ภาคผนวก) | แหล่งหลักของบทเรียน ตัวอย่าง ผลลัพธ์ และเฉลย |
| สไลด์อบรม 138 หน้าพร้อม Speaker Notes | ลำดับการสอน คำถามชวนคิด และ Final Quiz |
| Trainer Guide | ความเข้าใจผิดที่พบบ่อยและวิธีอธิบาย |
| SQL Cheat Sheet | หน้าสรุปสูตรย่อ |
| ไฟล์ SQL (ตัวอย่าง แบบฝึกหัด เฉลย Workshop) | แบบฝึกหัด 33 ข้อ และ Workshop 10 โจทย์ |
| ชุดข้อมูลฝึก (setup SQL และ CSV) | ข้อมูลของทุกตัวอย่าง (ดาวน์โหลดได้ที่ [หน้าชุดข้อมูล](#/reference/dataset)) |

**ไม่ได้เผยแพร่:** Pre-test, Post-test, Answer Key และเฉลย Final Project เพราะเป็นเอกสารสำหรับผู้สอนใช้ประเมินผล

## สิ่งที่ปรับปรุงจากเอกสารเดิม

- **จัดลำดับใหม่** เป็น 3 ระดับ (Beginner → Intermediate → Workplace) และแยกหัวข้อใหญ่เป็นบทย่อยที่เรียนจบได้ในครั้งเดียว
- **เพิ่มบทใหม่** ลำดับการประมวลผลของ SQL, UNION, Top 3 Products per Store แบบละเอียดทีละขั้น, ฟังก์ชันข้อความและตัวเลข, การเทียบปีก่อน (YoY), การอ่าน Error, การเขียน SQL ให้อ่านง่าย และพื้นฐาน Performance
- **SQL หนึ่ง Query อยู่ในกล่องโค้ดเดียวเสมอ** พร้อมคำอธิบายแยกนอกกล่อง และผลลัพธ์ที่ได้จากการรันจริง
- **แสดงข้อมูลต้นทางและผลลัพธ์**ของตัวอย่างหลัก ให้เห็นว่าข้อมูลเปลี่ยนอย่างไร
- **เพิ่มตัวตัดสิน (Tie-breaker)** ในตัวอย่างที่ใช้ `LIMIT` / `ROW_NUMBER` ให้ผลคงที่ทุกครั้ง
- **แก้ Cheat Sheet ข้อ Top N ต่อกลุ่ม** ที่อ้างตาราง `store_product` โดยไม่ได้สร้าง และไม่มีตัวตัดสิน
- **ตรวจพบกรณีพิเศษที่เอกสารเดิมไม่ได้ระบุ:** รายการ T0044 และ T0060 ยอดสุทธิติดลบเพราะส่วนลดมากกว่ายอดสินค้า จึงเพิ่มการตรวจนี้ในบทคุณภาพข้อมูล
- **เพิ่มแบบฝึกหัด 12 ข้อ** สำหรับหัวข้อใหม่ และตารางสอนเสริม 3 ตาราง

## วิธีตรวจความถูกต้อง

- **SQL ทุกกล่องที่มีผลลัพธ์ถูกรันจริง** กับชุดข้อมูลฝึกด้วยเครื่องมือ `tools/sqlcheck.py` แล้วเทียบผลกับตารางที่แสดงทีละเซลล์ ตารางข้อมูลต้นทางตัวอย่างก็ถูกตรวจด้วยวิธีเดียวกัน
- เครื่องมือใช้ **DuckDB** (ฐานข้อมูลที่ไวยากรณ์ใกล้เคียง) และแปลงฟังก์ชันเฉพาะของ Databricks บางตัวก่อนรัน
- ตัวเลขผลลัพธ์ของตัวอย่างที่มาจากเอกสารเดิมตรงกับเอกสารเดิม ซึ่งระบุว่าตรวจบน Apache Spark 4.0 (ANSI mode)

## ข้อจำกัดที่ควรรู้

- ยังไม่ได้รันทุก Query บน **Databricks Workspace จริง** ฟังก์ชันที่ DuckDB จำลองต่างจาก Databricks เล็กน้อยในบางกรณี (เช่น การหารด้วยศูนย์ใน DuckDB ไม่ Error) ตัวอย่างประเภทนั้นจึงไม่ได้ตรวจอัตโนมัติและระบุไว้ว่า "ตั้งใจให้ Error"
- ข้อความ Error ที่แสดงอาจต่างจากที่เห็นจริงเล็กน้อยตามเวอร์ชันของ Databricks แต่รหัส Error (ในวงเล็บเหลี่ยม) ใช้ค้นหาได้
- ชื่อเมนูและตำแหน่งปุ่มใน Databricks อาจต่างตามเวอร์ชันและการตั้งค่าขององค์กร
- **ความคืบหน้าการเรียน**บันทึกในเบราว์เซอร์เครื่องนั้นเท่านั้น (localStorage) ไม่มีการส่งข้อมูลไปที่ใด เปลี่ยนเครื่อง ใช้โหมดไม่ระบุตัวตน หรือล้างข้อมูลเบราว์เซอร์แล้วความคืบหน้าจะหายไป และผู้สอนไม่สามารถดูความคืบหน้าของผู้เรียนได้
- เว็บไซต์ไม่มีระบบรัน SQL ในหน้าเว็บ ต้องคัดลอกไปรันใน Databricks

## ความเป็นส่วนตัว

เว็บไซต์เป็น Static Site ไม่มีระบบสมาชิก ไม่มี Backend และไม่เก็บข้อมูลผู้ใช้ ใช้ฟอนต์จาก Google Fonts เท่านั้น ข้อมูลในทุกตัวอย่างเป็นข้อมูลจำลอง
