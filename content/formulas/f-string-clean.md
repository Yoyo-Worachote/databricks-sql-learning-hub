## สูตรนี้คืออะไร

ทำความสะอาดข้อความที่พิมพ์ไม่สม่ำเสมอ ก่อนนำไป JOIN หรือ GROUP BY

| ฟังก์ชัน | ทำอะไร | ตัวอย่าง |
|---|---|---|
| `TRIM(s)` | ตัดช่องว่างหัวท้าย | `' S02 '` → `'S02'` |
| `UPPER(s)` / `LOWER(s)` | เปลี่ยนตัวพิมพ์ | `'s03'` → `'S03'` |
| `REPLACE(s, a, b)` | แทนที่ข้อความ | `'1,250.00'` → `'1250.00'` |
| `REGEXP_REPLACE(s, pattern, b)` | แทนที่ตามรูปแบบ | ลบอักขระที่ไม่ใช่ตัวเลข |
| `NULLIF(TRIM(s), '')` | ข้อความว่างให้เป็น NULL | `'   '` → NULL |

## รูปแบบ (Syntax)

```sql
SELECT UPPER(TRIM(code_col)) AS code_clean
FROM table_name;
```

## ตัวอย่างข้อมูลต้นทาง

`sales_raw.store_code` (แสดงใน `[ ]` เพื่อให้เห็นช่องว่าง): `[S01]`, `[S02]`, `[s03]`, `[ S02 ]`, … มีรหัสต่างกัน 6 แบบ แต่จริง ๆ เป็นเพียง 4 สาขา

## SQL Query ฉบับเต็มและผลลัพธ์

```sql {verify}
SELECT
  raw_id,
  '[' || store_code || ']' AS store_code_shown,
  UPPER(TRIM(store_code))  AS store_id_clean
FROM sales_raw
ORDER BY raw_id;
```

| raw_id | store_code_shown | store_id_clean |
|---|---|---|
| 1 | [S01] | S01 |
| 2 | [S02] | S02 |
| 3 | [s03] | S03 |
| 4 | [S01] | S01 |
| 5 | [S04] | S04 |
| 6 | [ S02 ] | S02 |
| 7 | [S03] | S03 |
| 8 | [S04] | S04 |

## อธิบายทีละส่วน

ฟังก์ชันซ้อนทำงานจากในออกนอก: `TRIM` ตัดช่องว่างก่อน แล้ว `UPPER` เปลี่ยนเป็นตัวใหญ่ หลังทำความสะอาด JOIN กับ `stores` ได้ครบ 8 แถว (ก่อนทำได้แค่ 6)

## ข้อผิดพลาดที่พบบ่อย

- JOIN ด้วยรหัสดิบ แถวที่ตัวพิมพ์หรือช่องว่างต่างกันหายเงียบ ๆ
- ทำความสะอาดฝั่งเดียวของการ JOIN (ต้องให้ทั้งสองฝั่งอยู่ในรูปแบบเดียวกัน)
- ตรวจ `IS NULL` อย่างเดียว ลืมข้อความว่าง

## ข้อควรระวังและกรณีพิเศษ

- `TRIM` ตัดเฉพาะช่องว่างปกติ ช่องว่างพิเศษจากเว็บ/Excel (Non-breaking space) อาจต้องใช้ `REGEXP_REPLACE(s, '\\s+', '')`
- การแก้ข้อมูลใน Query ไม่ได้แก้ที่ต้นทาง ควรแจ้งเจ้าของข้อมูลด้วย

## วิธีอื่นที่ใช้แทนกันได้

- ตารางจับคู่รหัส (Mapping table) เมื่อรหัสผิดหลายแบบที่แก้ด้วยฟังก์ชันไม่ได้

## แบบฝึกหัด

**โจทย์:** นับจำนวนรหัสสาขาไม่ซ้ำใน `sales_raw` ก่อนและหลังทำความสะอาด

:::answer
```sql {verify}
SELECT
  COUNT(DISTINCT store_code)              AS raw_codes,
  COUNT(DISTINCT UPPER(TRIM(store_code))) AS clean_codes
FROM sales_raw;
```

| raw_codes | clean_codes |
|---|---|
| 6 | 4 |

**เหตุผล:** `'s03'` รวมกับ `'S03'` และ `' S02 '` รวมกับ `'S02'` เหลือ 4 สาขาจริง ถ้า GROUP BY ด้วยรหัสดิบ รายงานจะแยก S02 และ S03 เป็นสองกลุ่มผิด ๆ
:::
