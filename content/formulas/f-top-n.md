## สูตรนี้คืออะไร

`ORDER BY ... LIMIT n` เรียงข้อมูลแล้วตัดเอา n แถวแรก ได้ **Top N ของทั้งตาราง** (หรือของทั้งผลลัพธ์หลังกรอง)

**ใช้แก้ปัญหา:** หารายการที่มีค่าสูงสุด/ต่ำสุด N อันดับ เช่น รายการขายยอดสูงสุด 5 รายการ สินค้าราคาแพงที่สุด 3 ตัว

**ไม่เหมาะกับ:** Top N **ต่อกลุ่ม** เช่น Top 3 ต่อสาขา ต้องใช้ [Top N ต่อกลุ่ม](#/formula/f-top-n-per-group)

## รูปแบบ (Syntax)

```sql
SELECT column_1, value_col
FROM table_name
ORDER BY value_col DESC, tie_breaker_col
LIMIT 5;
```

## ตัวอย่างข้อมูลต้นทาง

ตาราง `sales` 141 แถว ยอดสุทธิ (`net_amount`) มีตั้งแต่ −30 ถึง 516 บาท

## SQL Query ฉบับเต็มและผลลัพธ์

**โจทย์:** รายการขาย 5 อันดับที่ยอดสุทธิสูงสุด

```sql {verify}
SELECT
  sale_id,
  sale_date,
  store_id,
  net_amount
FROM sales
ORDER BY net_amount DESC, sale_id
LIMIT 5;
```

| sale_id | sale_date | store_id | net_amount |
|---|---|---|---|
| T0022 | 2026-01-09 | S01 | 516.00 |
| T0052 | 2026-01-28 | S01 | 445.00 |
| T0058 | 2026-01-31 | S01 | 435.00 |
| T0096 | 2026-03-02 | S02 | 420.00 |
| T0077 | 2026-02-15 | S03 | 356.00 |

## อธิบายทีละส่วน

| ส่วน | ความหมาย |
|---|---|
| `ORDER BY net_amount DESC` | ยอดสูงสุดขึ้นก่อน |
| `, sale_id` | ตัวตัดสินเมื่อยอดเท่ากัน ทำให้ผลคงที่ |
| `LIMIT 5` | ตัด 5 แถวแรก**หลัง**เรียงแล้ว |

**ลำดับการทำงาน:** `FROM` → `WHERE` (ถ้ามี) → `SELECT` → `ORDER BY` (เรียงทั้งหมด) → `LIMIT` (ตัด)

## ข้อผิดพลาดที่พบบ่อย

- ใช้ `LIMIT` โดยไม่มี `ORDER BY` ได้ 5 แถวไหนก็ได้ ไม่ใช่ Top 5
- ไม่ใส่ตัวตัดสิน ถ้าอันดับ 5 และ 6 ยอดเท่ากัน ผลจะสลับไปมา (ในข้อมูลนี้อันดับ 6–7 ยอด 351 เท่ากัน)
- ลืม `DESC` ได้รายการยอดต่ำสุดแทน
- ใช้ `SELECT TOP 5` (ไวยากรณ์ SQL Server) ใน Databricks จะ Error

## ข้อควรระวังและกรณีพิเศษ

- รายการอันดับ 4 (T0096) คือการซื้อ 60 ชิ้นที่ผิดปกติ ก่อนรายงาน Top N ควรตรวจคุณภาพข้อมูล
- ถ้าต้องการให้รายการที่ยอดเท่ากับอันดับสุดท้ายติดอันดับทั้งหมด ให้ใช้ `RANK()` แล้วกรอง `rnk <= 5` แทน `LIMIT`

## วิธีอื่นที่ใช้แทนกันได้

- `RANK()` / `DENSE_RANK()` ใน CTE แล้วกรองชั้นนอก (จัดการค่าเท่ากันได้ยืดหยุ่นกว่า)
- Databricks: `QUALIFY RANK() OVER (ORDER BY net_amount DESC) <= 5`

## แบบฝึกหัด

**โจทย์:** หาสินค้า 3 อันดับที่ราคาป้ายต่ำที่สุด

:::answer
```sql {verify}
SELECT
  product_id,
  product_name,
  list_price
FROM products
ORDER BY list_price ASC, product_id
LIMIT 3;
```

| product_id | product_name | list_price |
|---|---|---|
| P001 | น้ำดื่ม 600ml | 7.00 |
| P005 | ขนมปังกรอบ 60g | 15.00 |
| P003 | กาแฟกระป๋อง 180ml | 18.00 |

**เหตุผล:** ต่ำสุดใช้ `ASC` (หรือไม่ระบุ) และใส่ `product_id` เป็นตัวตัดสินเผื่อราคาเท่ากัน
:::
